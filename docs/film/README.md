# Film app docs (`web/` and `video/`)

Everything here belongs to the 3D film app in `web/` and the 30 s video in `video/`. It is kept apart from the shared docs on purpose,
so adding it never conflicts with the team's edits to `docs/assumptions.md`, `docs/data-sources.md`, `docs/limitations.md` and `docs/log.md`.
If the film ships, fold these into the shared files.

| File | What it is |
|---|---|
| `design.md` | Visual direction (palette, type, copy and motion rules), in French |
| `single-film-design.md` | Why and how the app is one continuous 3D film: shots, camera, agent, performance budget |
| `assumptions.md` | Visual and modelling assumptions of the film app (numbered F1..) |
| `data-sources.md` | Data, services and fonts used by `web/` and `video/` |
| `limitations.md` | Known limits of the film app |
| `video-script.md` | 30 s script, ElevenLabs text, cut times from the recorded voice |
| `submission-draft.md` | Draft of the project page texts, to adapt to what ships |
| `log.md` | Session log for the film work |
| `../competition.md` | Public competitor projects found on GitHub, and where we differ |
